🛠️ 1. MÔI TRƯỜNG & QUẢN LÝ MÃ NGUỒN

  • Bộ ba công cụ: Git (Local máy) • GitHub (Cloud/Copilot) • GitLab (DevOps).
  • Cấu hình định danh: git config --global user.name & user.email (ký tên commit).
  • Chìa khóa SSH (Ed25519): Tạo key, copy public key dán lên GitHub ➔ Không cần gõ pass.
  • Personal Access Token (PAT): Bắt buộc dùng khi đẩy qua link HTTPS thay cho mật khẩu cũ.
  • Tấm khiên .gitignore (Sống còn): Chặn .env, API Key, node_modules/ đẩy lên mạng.
  • Chu trình 4 bước: git status ➔ add . ➔ commit -m ➔ push origin main.

🗺️ 2. TƯ DUY PHÁC THẢO USER FLOW

  • Chân lý cốt lõi: "5 phút vẽ User Flow rõ ràng = Tiết kiệm 5 tiếng sửa code cùng AI".
  • Bản đồ tư duy: Mô tả trọn vẹn luồng người dùng từ màn hình đầu tiên đến kết thúc.
  • Rẽ nhánh & Bẫy lỗi: Luôn vạch rõ: Khi đúng thì đi đâu? Khi sai/mất mạng báo lỗi gì?
  • Công cụ nhẹ nhàng: Vẽ giấy bút, text gạch đầu dòng, hoặc bảo AI vẽ Mermaid syntax.
  • Áp dụng cho anh Huy: Luồng Tải ảnh ➔ Dựng 3D ➔ Tùy chọn mặc định ➔ CNC.

⚡ 3. VŨ KHÍ PROMPT R-C-T-C-O

  • Tư duy Architect: Bạn định hướng & ra rào chắn; AI là thợ gõ siêu tốc chấp hành.
  • [R] Role: Gán vai trò chuyên gia (thu hẹp không gian tri thức, tránh code cẩu thả).
  • [C] Context: Cung cấp bối cảnh dự án, thư viện đang dùng (HTML/CSS, Ruby SketchUp).
  • [T] Task: Nhiệm vụ đơn nhất, dùng động từ mạnh (Xây dựng, Tái cấu trúc, Bóc tách).
  • [C] Constraints: Rào chắn & điều cấm (Không thư viện ngoài, tối ưu bộ nhớ).
  • [O] Output: Định dạng kết quả chính xác (Block code, JSON, kèm hướng dẫn).
  • Phân rã (Decomposition): Không nhồi nhét, chia nhỏ bài toán để không nghẽn token.
