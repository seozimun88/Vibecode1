🌐 1. TỔNG QUAN ĐA NỀN TẢNG
🟢 ĐÈN XANH (00:15 - 00:55)
  • Write Once, Run Everywhere: Xây 1 bộ mã nguồn Web (HTML/CSS/JS) chạy khắp Web, Android, iOS.
  • PWA vs Capacitor vs Native: PWA: 0$ phí store, offline cache. Capacitor: Gói APK/IPA, gọi phần cứng native.
  • Tư duy Mobile UX (Thumb Zone & Safe Area): Nút bấm đặt ở nửa dưới màn hình (dễ với ngón cái), padding tránh tai thỏ & dynamic island.
  • Haptic Feedback: Rung phản hồi 15ms khi chạm nút, tạo cảm giác thỏa mãn như bấm phím vật lý.
📦 2. BIÊN DỊCH BẰNG CAPACITOR
🟢 ĐÈN XANH (00:55 - 01:50)
  • Khởi tạo & Cấu hình (B1-B2): npm i @capacitor/core @capacitor/cli → npx cap init (Tên app + App ID).
  • Sinh Assets tự động (B3): Chỉ cần 1 icon.png + 1 splash.png → npx @capacitor/assets sinh mọi cỡ ảnh.
  • Đồng bộ mã nguồn (B4-B5): npx cap add android → npx cap sync (Lệnh sống còn mỗi khi sửa web).
  • Xuất file APK & Cài máy thật: Build APK debug gửi qua Zalo/Drive; Chạy máy thật qua Cáp USB / Wi-Fi QR Code.

⚡ 3. ĐỒNG BỘ REALTIME (PUB/SUB)
🟢 ĐÈN XANH (02:05 - 02:45)
  • Tiến hóa: Polling → SSE → CDC: Bỏ Polling (hỏi dồn dập tốn pin) → Dùng Supabase CDC bắt biến động DB tức thì.
  • Mô hình Pub/Sub (5 Dòng Code): supabase.channel('...').on('postgres_changes', {event:'INSERT'}).subscribe().
  • Optimistic UI (Cập nhật lạc quan): Đổi màu giao diện mili-giây thứ 0, gửi ngầm dữ liệu lên server. Trải nghiệm tức thì!
  • Giải quyết tranh chấp (Last-Write-Wins): Sử dụng Timestamp để ưu tiên thao tác mới nhất khi nhiều máy cùng sửa dữ liệu.
🔍 4. MÁY ẢO & ĐỌC VỊ BẮT LỖI
🟢 ĐÈN XANH (02:45 - 03:25)
  • Máy ảo AVD Android: Tạo Pixel 8 (API 34/35) trên Android Studio để test cảm ứng, xoay màn hình 0 đồng.
  • Vũ khí Chrome Remote Debugging: Gõ chrome://inspect/#devices → Bấm Inspect soi trọn Console, Elements, Network trên app!
  • Bắt 3 ca bệnh kinh điển: Trắng màn hình (lỗi link tương đối); Lỗi nạp Supabase (sai thứ tự script); Sập mảng index.
  • Bí kíp Prompt AI sửa lỗi: Dán nguyên văn [Tên lỗi + Stack Trace + Dòng code] để AI viết defensive code dứt điểm.
